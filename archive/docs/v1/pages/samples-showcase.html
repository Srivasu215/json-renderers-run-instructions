The 4 Architectural Tiers in Action

From micro input primitives to fully-wired Master-Detail dashboards. Explore how each sample in this repository demonstrates declarative instruction execution.

Tier 1 • Direct Leaf Elements Primitive Inputs

Direct Controls

Direct components represent single leaf input elements rendered directly from data collections with no wrapping structural containers. Ideal for dropdowns, autocompletion inputs, and choice pickers.

Tier 2 • Functional Units Structural Blocks

Container Components

Containers encapsulate child layouts and execute 2D Cartesian instructions. This repository provides rich container implementations:

Tier 3 • Compound Layouts Higher-Order Views

Compose Layouts

Orchestrates multiple container types into cohesive compound interfaces such as multi-widget analytics dashboards or synchronized form-and-control panels.

Tier 4 • Master-Detail Workflows Interactive Systems

Composite Interactive Systems

The highest tier combines data rendering with live user interactions. The master table renders items; clicking an "Edit" action automatically extracts row data, hydrates an adjacent Form, and triggers live autocompletion through a rendered DataList.

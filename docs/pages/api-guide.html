Developer Reference

API Reference & Usage Guide

Complete instructions for installing, configuring, and invoking the instruction runner in Node.js and browser environments.

Installation

Via npm
npm install json-renderers-run-instructions
Via Browser CDN (ES Module)
<script type="module">
  import { runInstructions } from "https://keshavsoft.github.io/json-renderers-run-instructions/dist/min.js";
</script>

Core API: runInstructions(options)

The primary entry point of the library. Synchronously executes Single (1D) and Double (2D) instructions against the provided registry blackboard.

Parameters
Property Type Default Description
registry Object Required The in-memory blackboard containing data (source collections) and base (target spec tree).
single Array [] Array of 1D single instruction descriptor objects for headers, columns, and leaf transformations.
double Array [] Array of 2D double instruction descriptor objects for row × column matrix operations.
showLog Boolean false When set to true, outputs verbose internal debugging and step snapshots to the console.
Complete Usage Example
import { runInstructions } from "json-renderers-run-instructions";

// 1. Initial base tree structure
const base = {
    tagName: "table",
    children: [
        { tagName: "thead", children: [{ tagName: "tr", children: [] }] },
        { tagName: "tbody", children: [] }
    ]
};

// 2. Data payload
const data = {
    columns: [
        { key: "sku", title: "SKU" },
        { key: "product", title: "Product Name" },
        { key: "price", title: "Price" }
    ],
    data: [
        { sku: "A-01", product: "Wireless Mouse", price: 29.99 },
        { sku: "B-02", product: "USB-C Hub", price: 49.99 }
    ]
};

// 3. Execution
runInstructions({
    single: [
        {
            source: "data.columns",
            template: "headers.th",
            target: "base.children[0].children[0].children"
        }
    ],
    double: [
        {
            outerSource: "data.data",
            innerSource: "data.columns",
            template: "cells.td",
            target: "base.children[1].children"
        }
    ],
    registry: { data, base }
});

console.log("Generated specification:", base);
